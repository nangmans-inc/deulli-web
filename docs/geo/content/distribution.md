# 외부 소개용 원고

아래는 미게시 원고다. 외부 전송과 게시를 수행하지 않았다. 플랫폼별 광고·홍보 규칙과 계정 권한을 확인한 뒤 사용한다.

## 짧은 설명

들리(deulli)는 영어 팟캐스트를 들으며 영어 스크립트와 한국어 번역을 확인하고, 놓친 문장부터 다시 들을 수 있는 학습 앱입니다. iOS와 Android를 지원합니다. https://deulli.com

## 개발자 소개 글

영어 팟캐스트 학습 앱 들리(deulli)를 만들고 있습니다.

들리에서는 팟캐스트를 듣다가 놓친 내용을 영어 스크립트와 한국어 번역으로 확인하고, 그 문장부터 다시 들을 수 있습니다. 학습 플레이어에는 배속과 이전·다음 대화 이동 기능이 있습니다.

팟캐스트로 공부할 때 어떤 부분에서 가장 자주 멈추는지 궁금합니다. 모르는 단어인지, 소리가 이어져 들리는 부분인지, 내용을 다시 찾는 과정인지 알려주시면 제품 개선에 참고하겠습니다.

공식 소개와 다운로드: https://deulli.com
