# 스토어 정보 보강안 · 아직 적용하지 않음

실제 API 답변에서 공식 홈페이지, Android 등록, 한국어 텍스트 번역의 근거를 찾지 못하는 사례가 있어 준비한 수정안이다. 현재 스토어 관리 계정에 접근하지 않았으며 아래 내용은 미적용이다.

## App Store의 마케팅 URL

`https://deulli.com`

공개 iTunes Lookup 응답에서 `sellerUrl`은 반환되지 않았다. 이것만으로 App Store Connect의 모든 관련 필드가 비어 있다고 단정할 수는 없다. 계정에서 현재 값을 확인하고 공식 홈페이지로 연결한다.

## 앱 소개 앞부분에 넣을 설명

> 들리(deulli)는 영어 팟캐스트를 들으며 공부하는 앱입니다. 재생되는 내용을 영어 스크립트와 한국어 번역으로 확인하고, 놓친 문장부터 다시 들을 수 있습니다. 들리 공식 채널의 진행자별 음성 언어 선택은 화면에서 번역을 확인하는 기능과 별도로 제공됩니다.

본문의 기능별 이용 조건, 가격, 구독·결제·체험 고지는 현재 승인된 내용을 기준으로 유지한다. 이번 원고는 그 조건을 변경하는 제안이 아니다.

## 공식 링크

```text
공식 홈페이지: https://deulli.com
들리 앱 소개: https://deulli.com/about/
iPhone: https://apps.apple.com/kr/app/id6798545609
Android: https://play.google.com/store/apps/details?id=com.deulli.app
이메일 문의: contact@deulli.com
```

Google Play 공개 소개의 이메일 안내에는 `https://contact@deulli.com`이라는 문자열이 있었다. 이메일은 `contact@deulli.com`으로 표기하고 홈페이지는 별도 HTTPS 주소로 명시한다. 웹사이트 설정 필드 전체가 이 이메일 주소로 설정됐다고 단정하지 않는다.

## 적용 후 확인할 것

관리 화면의 저장·심사 상태와 실제 공개 스토어 본문을 별도로 확인한다. 스토어가 변경됐다고 검색 색인이나 AI 답변이 즉시 바뀌는 것은 아니다. 공식 홈페이지를 질문에 미리 넣지 않은 동일 질문으로 후속 확인한다.

## 위클리 소개 문안 (2026-11-10 추가, 미적용)

2026-11-10 기준 App Store 한국 소개(1.5.2)에 위클리 설명이 없다. 소개 글 앞부분의 기능 목록 위에 아래 문단을 넣는다.

> 위클리 - 듣고 싶은 이야기를 적으면 들리가 그 주제로 팟캐스트 두 편을 만들어 일주일 치 듣기 미션으로 나눠 드려요. 하루에 미션 하나를 듣고, 7일차에 한 주를 돌아봐요.

공식 링크에 `위클리 소개: https://deulli.com/weekly/`를 추가한다. 체험·요금 문구는 현재 승인된 스토어 문구를 그대로 둔다.
