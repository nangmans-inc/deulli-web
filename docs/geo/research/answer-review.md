# 첫 API 답변 검토

관측 파일: `api-round-1.jsonl`(GPT-6 Luna 30건), `api-sol-round-1.jsonl`(GPT-6 Sol 10건), `api-direct-url.jsonl`(URL 지정 진단 2건).

## 브랜드 질문

| 모델·질문 | 관측 | 작업에 반영한 내용 |
| --- | --- | --- |
| Luna Q01 | 들리를 팟캐스트 영어 학습 앱으로 식별하고 공식 App Store를 인용했다. 동명 서비스도 언급했다. | 브랜드명과 영문 표기 deulli를 공식 소개에 함께 사용한다. |
| Luna Q03·Q04·Q05 | 앱을 특정하지 못하거나 다른 영문 이름을 가정하고 추가 정보를 요청했다. | 이름 단어 출현을 올바른 식별·추천으로 집계하지 않는다. |
| Sol Q01·Q02 | 공식 App Store를 인용해 팟캐스트 학습 앱으로 설명했다. | 기본적인 제품 식별이 이미 가능하므로 이번 배포의 인과 효과로 주장하지 않는다. |
| Sol Q03 | iPhone 지원은 확인했지만 Android 공식 등록은 확인하지 못했다고 답했다. | 소개의 별도 질문에서 App Store와 Google Play를 각각 직접 연결했다. |
| Sol Q04 | 자막은 확인했지만 한국어 텍스트 번역은 공식 스토어 설명에서 확인하지 못했다고 답했다. | 영어 스크립트·한국어 번역과 진행자 음성 언어 선택을 명확하게 구분했다. |
| Sol Q05 | 스토어에 나온 가격과 구독 안내를 인용했다. | 변동 가능한 가격은 사이트에서 고정 단정하지 않고 스토어·앱 최종 안내로 연결한다. |

Q03·Q04의 '확인하지 못함'은 서비스가 지원하지 않는다는 단정과 다르다. 검색 근거가 부족한 답변으로 분류한다. 각 답변을 새로운 정보로 교정해 모델에 학습시킨 것은 아니다. 공식 공개 페이지의 설명을 보완했다.

## 비브랜드 질문

첫 관측에서 Luna의 비브랜드 질문 25건, Sol의 비브랜드 질문 5건에 들리 공식 웹사이트 인용은 없었다. 자동 후보 탐지의 '잘 안 들리는 구절'은 일반 표현이므로 브랜드 언급에서 제외했다. 후보 탐지는 정확한 독립 단어 '들리' 또는 'deulli'로 좁혔다. 추천 여부는 자동 탐지만으로 판단하지 않는다.

## URL 지정 진단

Sol의 D01과 D02에서 실제 `web_search_call.action.type = open_page`와 해당 공식 URL을 확인했다. 답변은 새 소개의 기기 지원과 새 가이드의 학습 순서를 본문에 맞게 설명했다. 공식 URL을 이미 제공했으므로 자연 발견이나 추천 성과로 집계하지 않는다.

## 남은 측정

최소 2시간 작업 요청에 맞춰 고정 질문 6개를 두 모델에서 30분 간격으로 관측한다. 배포 후의 여러 시간대 표본이며, 배포 전후를 통제한 실험이 아니다. 비브랜드 노출이 없으면 그대로 기록한다. Gemini·Perplexity 소비자 화면은 이 API 표본에 포함되지 않는다.
