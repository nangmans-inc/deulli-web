# 실제 AI 답변 확인

OpenAI Responses API에서 앞선 대화나 제품 원고를 전달하지 않고 독립 요청으로 수집했다. 모델은 GPT-6 Sol이며 검색을 사용했다. 소비자용 ChatGPT 화면의 결과는 아니다.

## 브랜드 이름만 물었을 때

질문: “들리 앱은 어떤 앱인가요?”

답변은 들리를 팟캐스트 영어 학습 앱으로 설명하고 공식 App Store를 인용했다. 자막·단어 저장·쉐도잉·퀴즈를 소개했다. 이 식별은 이미 스토어 자료로 가능했으므로 이번 웹 변경의 성과라고 주장하지 않는다.

원문: `api-sol-round-1.jsonl`의 Q01. [인용된 공식 App Store](https://apps.apple.com/kr/app/id6798545609).

추가로 홈페이지 주소 없이 '들리(deulli)라는 영어 팟캐스트 학습 앱은 어떤 서비스인가요?'라고 물은 B01에서도 두 모델이 공식 App Store를 인용해 기본 서비스를 설명했다. 원문은 `api-brand-context-gpt-6-luna.jsonl`과 `api-brand-context-gpt-6-sol.jsonl`에 있다. 같은 질문 묶음에서도 Android·번역 설명의 근거 부족은 남아 있어, 기본 식별과 모든 기능의 정확한 설명을 구분한다.

## 공개한 소개 페이지를 알려줬을 때

질문에 `https://deulli.com/about/`를 직접 포함했다.

실제 검색 작업의 `open_page`와 공식 소개 URL을 확인했다. 답변은 영어 팟캐스트 학습, 영어 스크립트·한국어 번역, 문장부터 다시 듣기, iOS·Android 지원을 설명했다.

원문: `api-direct-url.jsonl`의 D01. [읽고 인용한 소개 페이지](https://deulli.com/about/).

## 가이드를 알려줬을 때

- D02: [팟캐스트 학습 가이드](https://deulli.com/guides/podcast-listening/)의 먼저 듣기 → 스크립트 확인 → 뜻 확인 후 재청취 → 한 문장 따라 말하기를 요약했다.
- D03: [앱 선택 가이드](https://deulli.com/guides/choosing-a-podcast-app/)의 콘텐츠·대본과 번역·문장 이동·복습·기기와 요금 조건을 요약했다.

두 답변 모두 실제 `open_page`와 해당 공식 페이지 인용을 확인했다.

## 실제 콘텐츠 페이지를 알려줬을 때

D05는 [공식 팟캐스트 소개](https://deulli.com/podcasts/)를 실제로 열고 다음 세 에피소드를 답했다.

- 민호의 Part 2 미니 모의고사
- 수메르: 문자는 왜 이야기보다 장부에서 먼저 필요했을까
- 왜 내 손으로는 나를 간지럽힐 수 없을까

에피소드 제목을 누르면 공유 페이지로 이동하고 실제 듣기·학습은 앱에서 이용한다는 안내도 본문과 일치했다. 원문은 `api-episodes-url.jsonl`에 있다.

## 이 증거가 뜻하는 범위

공개 페이지를 읽고 근거로 인용하는 것은 확인했다. URL을 제공한 검사는 자연 검색 발견이나 추천 순위의 증거가 아니다. URL을 제공하지 않은 일반 질문·브랜드 홈페이지 찾기·제품 기능에서 도출한 탐색 질문은 별도로 수집하며, 결과는 `api-summary.md`와 각 JSONL에 기록한다.

본문을 공개한 것으로 모델의 공통 학습 데이터가 즉시 바뀌었다고 주장하지 않는다. 검색 기반 접근·인용과 자연 발견을 구분한다.
