# Search Console 실행 결과 · 2026-11-06

이번 작업에 대해 사용자가 브라우저 조작과 소유권 등록·사이트맵·색인 요청을 승인했다.

- URL 접두어 속성: `https://deulli.com/`
- 소유권: 기존 Google Analytics 태그를 통한 자동 확인 완료. 별도 인증 파일이나 새 스크립트는 추가하지 않았다.
- `https://deulli.com/sitemap-index.xml` 제출 완료. 최초에는 가져올 수 없음이었으나 같은 세션에서 재확인한 결과 **성공**으로 변경됐다. 표의 발견 페이지 수는 0으로 표시됐으므로 모든 페이지 발견 완료로 해석하지 않는다.
- 홈페이지 검사: **Google에 등록되어 있음**. 최신 내용의 색인 생성 요청 후 우선순위 크롤링 대기열에 추가됐다는 완료 화면을 확인했다.
- `/about/`, `/guides/podcast-listening/`, `/guides/choosing-a-podcast-app/`, `/podcasts/`: 검사 시 Google에 아직 알려지지 않은 URL. 각각 색인 생성 요청 후 우선순위 크롤링 대기열 추가 완료 화면을 확인했다.

요청 접수는 색인·순위·AI 인용 완료가 아니다. 새 속성의 실적 데이터는 처리 중이었다. 홈페이지가 이미 색인돼 있었으므로 공개 검색 도구에서 결과가 안 나온다는 이유로 사이트 전체가 Google 미색인이라고 결론 내리지 않는다.
