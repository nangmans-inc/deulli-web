# 공개 설명 페이지 검증

Design Read: 들리 앱을 알아보는 학습자를 위한 제품 설명·학습 안내. 기존 Figma 기반 Pretendard·네이비·블루와 문장 중심 구성을 사용한다. ENERGY 1 / RHYTHM 1 / MOTION 1. 본문 제목을 초점으로 두고 블루는 이동 링크에 사용한다. 새 장식·아이콘·애니메이션은 추가하지 않는다.

- Hard Gate PASS: 홈·소개·가이드 3개를 headless Chrome에서 320/390/768/1440px로 검사했고 가로 넘침이 없다. 링크에는 이름과 실제 목적지가 있다. Tab으로 첫 링크 이동 및 outline 표시 확인. 새 본문에 가짜 후기·성과 수치·무료 가격 단정이 없다. 정적 페이지라 비동기 상태는 해당하지 않는다.
- Purpose Gate PASS: 기존 로고·서체·색 토큰·스토어 배지만 재사용했다. 제목 크기는 읽기 위계, 문단 간격은 설명 구분, 파란 밑줄은 이동 가능한 링크를 식별하기 위한 것이다.
- Liveliness PASS: 제목·본문의 크기 대비, 여백으로 구분한 질문·설명, 들리 로고와 문장 중심 구성으로 기존 브랜드 방향을 유지한다. 선언한 낮은 에너지·균일한 읽기 리듬·추가 동작 없음과 일치한다.
- Craftsmanship PASS: Astro 검사·ESLint 오류와 경고 0개, 프로덕션 빌드 성공, 기존 테스트 53개 통과, 빌드된 SSR HTTP 검사 통과. 소개·가이드 모바일과 데스크톱 전체 화면을 확인했다. 정책·고객지원 3개 URL의 HTTP 200 확인. 기본 본문 #041225, 설명 #33465d, 링크 #0150e5는 흰 배경에서 AA 대비를 충족한다. 재료 출처는 저장소 제품 데이터와 공식 스토어 설명이다.

검증 범위는 이번에 추가·변경한 소개 영역과 설명 페이지다. 사용자 Chrome 창·앱·개발 서버를 조작하지 않고 별도 headless 인스턴스와 작업 전용 정적 서버를 사용했다. GA·Meta 외부 요청은 렌더링 검사에서 차단했다.

후속 앱 선택 가이드를 포함한 4페이지를 같은 4개 너비에서 다시 검사했다. 390px 비교표와 전체 본문 화면을 확인했고 넘침이 없다. 실제 운영 사이트에서 홈 → 소개 → 학습 가이드 링크 이동과 `store_click`의 `app_store`·`google_play` label 발생을 확인했다. 이 검사에서도 분석 서버로의 요청은 차단해 운영 데이터에 테스트 이벤트를 보내지 않았다.

공식 에피소드 소개를 포함한 5페이지도 320/390/768/1440px에서 가로 넘침·링크 이름·키보드 포커스 검사를 통과했다. 에피소드 세 개의 제목·공개 상태는 기존 카탈로그 표본에서 고른 ID의 익명 공개 메타데이터로 확인했다. 운영 공유 URL 세 개도 HTTP 200·정확한 canonical·index 허용 상태를 확인했다. 에피소드 설명이 없는 경우 설명을 만들어 넣지 않고 확인한 제목과 실제 공유 링크를 제공한다. 같은 읽기 레이아웃과 기존 브랜드 토큰을 사용하며 새 장식과 동작을 추가하지 않았다.

영어공부 시작법·목적별 앱 선택 가이드를 포함한 6페이지를 동일한 4개 너비에서 검사했다. 모바일 전체 화면에서 제목·본문·목록·스토어 링크를 확인했다. 기존 읽기 레이아웃과 브랜드 토큰을 유지하고 학습 순서는 제안으로 구분했다. lint·build 및 넘침·링크 이름·키보드 포커스 검사가 모두 통과했다. Hard/Purpose/Liveliness/Craftsmanship Gate PASS.

야간 후속 변경에서는 앱 선택 가이드를 포함한 7페이지를 320/390/768/1440px에서 검사했다. 새 가이드와 팟캐스트 자료 링크, 앱 분류 난이도, 연구 범위를 구분한 본문을 기존 GuideLayout에 추가했다. lint는 오류·경고 0개였고 build가 성공했다. 링크 이름·가로 넘침·키보드 포커스 검사가 통과했으며 새 가이드의 모바일 전체 화면을 확인했다. Hard/Purpose/Liveliness/Craftsmanship Gate PASS. 이 검증은 로컬 변경본의 품질 검사이며 운영 배포 확인을 뜻하지 않는다.

별도 로컬 진행 화면도 같은 4개 너비에서 검사했다. 실제 수집 건수와 프로세스 상태를 표시하고 측정 사이의 대기를 명시한다. 모바일 화면·포커스·넘침 검사 통과. 정책 저장소 draft PR #5는 분리 worktree의 기존 6개 페이지에 공식 홈페이지 링크만 추가했으며 4개 너비에서 넘침·포커스·링크 목적지·44px 클릭 영역을 확인했다. 기존 법률 본문을 바꾸지 않았고 이 PR은 병합·배포하지 않았다.
