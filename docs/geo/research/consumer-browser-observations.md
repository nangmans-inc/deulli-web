# 소비자용 AI 화면 관측 · 2026-11-06

사용자의 이번 GEO 작업 한정 브라우저 허용 후 실제 Chrome 화면에서 확인했다. API 결과와 별도 표본이며, 순위·지속 노출·개선의 인과관계를 뜻하지 않는다. 개인 계정 식별자, 대화 주소, 기존 대화 내용은 공개 기록에 포함하지 않는다.

| 서비스·조건 | 독립 질문 | 관측 결과 |
| --- | --- | --- |
| ChatGPT, 임시 대화, 개인화되지 않음 선택, 화면에 모델명 미표시 | 들리(deulli)라는 영어 팟캐스트 학습 앱은 어떤 서비스인가요? 웹에서 확인하고 출처를 알려주세요. | 영어 팟캐스트 학습 앱으로 식별. 자막·어휘·받아쓰기 등 설명. App Store와 공식 정책 사이트를 인용했고 deulli.com은 인용하지 않음. |
| Gemini, Flash, 새 임시 대화 | 영어공부 어플 추천해줘. | Speak, ELSA Speak, Cake, Duolingo, Cambly 추천. 들리 언급 없음. 출처 표시 있음. |
| Gemini, Flash, 새 임시 대화 | 팟캐스트 영어공부 추천해줘. | 필요한 정보나 능력이 없다는 거절 답변. 제품 추천 답변으로 집계하지 않음. |
| Gemini, Flash, 새 임시 대화 | 영어공부하는 법 알려줘. | 수준별·영역별 학습법과 Speak 등 도구 제안. 들리 언급 없음. 보이는 답변 본문에 출처 표시는 없었음. |

ChatGPT 브랜드 답변에는 타사 앱의 이미지가 함께 표시됐고 월 구독 가격도 단정했다. 이 이미지와 요금 주기는 공식 홈페이지에서 검증한 제품 정보로 채택하지 않았다. 브랜드를 먼저 알려준 답변이므로 자연 추천 성공으로 집계하지 않는다.

Gemini의 임시 대화 표시는 확인했으나 계정 전체 개인화 설정까지 변경·검증하지 않았다. 각 질문은 새 임시 대화에서 입력했다. 추천 앱의 기능 설명은 모델 출력이며 이번 문서가 해당 기능의 사실성을 검증한 것은 아니다.
