# 첫 야간 답변의 인용 적합성 점검

검토 대상은 오전 3시 30분의 비브랜드 답변 12개에서 선택한 공식 페이지의 설명이다. 학습 효과나 실제 앱 동작을 비교한 검토는 아니다.

**결론:** 공식 도메인의 링크가 붙었다고 추천 문장이 입증되는 것은 아니다. BBC 추천에 British Council 자사 앱 페이지를 붙인 사례는 근거가 맞지 않았다. 다른 공식 기능 설명도 제품 페이지에 적힌 내용으로 한정해서 채택했다.

| 주장 | 판단 | 확인 범위 |
| --- | --- | --- |
| BBC 제품 추천에 붙인 British Council 앱 페이지가 그 BBC 기능을 입증한다 | 근거 부족 | 해당 페이지는 British Council 자체 앱을 안내한다 |
| British Council Podcasts 페이지가 A2·B1, 대본과 연습문제를 안내한다 | 페이지 설명은 직접 확인 | 모든 초급자에게 적합하거나 효과가 검증됐다는 뜻은 아니다 |
| LingQ 공식 iOS 안내에 대본·어휘 저장·SRS 설명이 있다 | 페이지 설명은 직접 확인 | 앱 사용 검증이나 Android 버전 기능 보장은 아니다 |
| 열람한 VoiceTube 페이지로 한국어 번역 지원을 확인할 수 있다 | 근거 부족 | 영어·중국어 설명은 있으나 한국어 지원 여부는 미확인 |

## 결정 근거와 반대 자료

- [British Council 앱 소개](https://www.britishcouncil.org/english/learn-online/resources-apps)의 Apps for English listening 절은 LearnEnglish Podcasts를 설명한다. BBC 제품과 같은 서비스로 취급하지 않는다.
- [Podcasts](https://learnenglish.britishcouncil.org/general-english/audio-series/podcasts)의 도입부에서 A2·B1 대상과 대본·상호작용 연습문제를 확인했다.
- [LingQ iOS 안내](https://www.lingq.com/en/ios-app/)의 See how it works, Integrated dictionary, SRS review system 절에서 해당 설명을 확인했다. 공식 포럼의 최근 Android 베타 이슈도 검색됐으므로 플랫폼과 버전을 넘는 단정은 하지 않는다.
- [VoiceTube 소개](https://www.voicetube.com/app/)의 학습 순서는 영어·중국어 자막을 언급한다. 한국어를 찾지 못한 것을 한국어 미지원의 증거로 바꾸지 않는다.

## 이 검토가 입증하지 않는 것

네 서비스의 학습 효과, 학습자별 적합성, 최신 모든 앱 버전의 기능, 유료 이용 조건을 검증하지 않았다. 들리가 이들보다 우수하다거나 앞으로 AI 추천에 등장할 것이라는 근거도 아니다. 비교 가이드에는 공식 설명으로 확인한 기능과 선택할 과제만 사용한다.

## 검토 대기 항목

최종 판단에 영향을 줄 수 있는 위치는 위 네 공식 페이지의 명시된 절이다. BBC와 British Council의 제품 식별, 한국어 지원의 명시 여부, ‘제품 페이지가 말한다’와 ‘실제로 효과가 있다’의 구분을 확인하면 판단을 재검토할 수 있다. 이 대기 목록은 작업을 멈추기 위한 승인 요청이 아니다.

검토 방식은 rapid, 검색일은 2026-11-06이다. 공식 제품·자료 페이지와 지원·업데이트 정보를 제한적으로 검색했고 학술 효과 검토는 하지 않았다. 출처·주장 연결 JSON은 `citation-fit-audit.json`에 있다. 구조 검증 오류 0개이며, 빠른 비포괄 검토에서 공식 페이지의 명시적 설명을 강하게 확인한 두 항목에 대해 검색 범위 주의 2개가 남았다.
