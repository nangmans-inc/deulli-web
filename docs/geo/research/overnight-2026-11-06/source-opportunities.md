# 넓은 질문의 출처와 들리의 설명 보강 기회

## 실제 답변에 등장한 출처

기존 넓은 의도 18개 API 답변에서는 British Council의 LearnEnglish 도메인이 20회 인용됐다. 같은 답변의 여러 인용도 포함한 수치이며 20개 독립 추천이나 검색 순위가 아니다. Duolingo 도메인은 3회, Apple Podcasts는 2회였다. 전체 목록과 원문은 `../api-broad-intent-*.jsonl`에 있다. 야간 표본이 쌓이면 현재 폴더의 집계와 구분해 비교한다.

단순히 경쟁사 이름을 늘어놓기보다 질문의 의도가 무엇인지 나누어야 한다. ‘영어공부 앱’ 답변에는 회화·발음·학습 습관 등 서로 다른 목적의 앱이 함께 나오고, ‘팟캐스트 영어공부’ 답변에는 플레이어 앱보다 콘텐츠 채널이 먼저 등장했다.

## 공식 출처에서 직접 확인한 내용

- [Speak](https://www.speak.com/): 표현 학습, 반복 연습, AI 튜터와의 대화를 설명하고 시작 방법·요금·제품 정의 FAQ를 공개한다. 들리도 사용 상황과 시작 순서를 검색 가능한 문장으로 제공할 수 있다. Speak가 제공하는 기능을 들리에 있다고 옮겨 적지는 않는다.
- [Cake 회사 소개](https://cakecorp.com/ko/): 영어공부 앱이라는 제품 분류와 서비스 연결을 공개한다. 페이지의 뉴스·다운로드 수는 과거 자료이므로 현재 성과 비교에 사용하지 않는다.
- [British Council 듣기 자료](https://learnenglish.britishcouncil.org/free-resources/listening): A1~C1 수준별로 상황과 학습 자료를 안내한다. 후속 공식 에피소드 응답에서 확인한 앱 분류 B1·A2·B2는 해당 3개에만 명시한다. 외부 공인 평가나 학습자 적합성 검증으로 확대하지 않는다. 대신 짧게 듣고 자료가 맞는지 고르는 기준을 안내한다.
- [VOA Learning English 팟캐스트](https://learningenglish.voanews.com/podcasts): 주제별 채널, Apple Podcasts와 구독 경로를 제공한다. Learning English Podcast에 대해서는 제한된 어휘·짧은 문장·다른 VOA 방송보다 느린 속도를 설명한다. 들리 자체의 효과나 VOA 콘텐츠 제공 여부를 증명하는 출처는 아니다.

## 이미 한 일과 다음 검토

1. 넓은 질문을 수용하는 영어공부 시작법·앱 선택 가이드는 main에 병합했다. 후속 PR #21 반영 뒤 두 운영 URL의 200과 본문을 확인했다. 직접 배포 서비스 조작은 하지 않았다. 공개 성공을 검색 유입 개선의 원인으로 주장하지 않는다.
2. 운영 중인 소개·팟캐스트 학습·앱 선택 가이드·공식 에피소드 목록은 이미 확인한 제품 기능과 공개 링크를 제공한다. Search Console에서 요청한 페이지의 색인 상태와 AI의 자연 발견을 별도 관측한다.
3. 스토어 설명의 홈페이지 연결·연락처 표기 수정안은 준비했지만 미적용이다. 앱스토어에만 의존하는 브랜드 설명을 줄일 수 있는 작업 후보로 남긴다.
4. 팟캐스트 추천 질문에서는 ‘어떤 앱인가’와 ‘무엇을 들을까’를 구분한다. 확인한 공식 에피소드 3개는 콘텐츠 진입점으로 쓸 수 있지만, 효과·난이도·대상 수준은 검증 없이 추가하지 않는다.
5. 모델이 BBC 이름과 함께 제시한 `bbclearningenglish.org` 링크는 BBC 소유 여부를 확인하지 않았으므로 검증된 공식 출처 목록에서 제외했다. AI가 붙인 출처도 그대로 신뢰하지 않는다.

이 기록은 노출 원인에 대한 가설과 실행 후보이며 경쟁사 순위·GEO 인과 효과를 증명하지 않는다. 외부 게시·커뮤니티 메시지·사용자 연락은 하지 않았다.

## 현재 스토어와 검색 설명의 시차

03:42 한국 시간의 iTunes Lookup은 1.5.1, 현재 버전 공개 시각 2026-11-05 04:06:36 UTC를 반환했다. 현재 설명에는 ‘80분’, ‘월 14,900’, ‘생성 탭’ 문자열이 없었으나 같은 시점 공개 검색 도구는 그 문구가 포함된 App Store 결과를 반환했다. 현재 설명 해시와 확인 값은 `store-current-metadata.json`에 보존했다. 문자열 부재는 요금이나 할당량이 실제로 변경됐다는 증거가 아니므로 현재 조건을 임의로 새로 쓰지 않는다.

공식 지원 페이지에는 웹 설정과 같은 운영자·지원 이메일이 확인됐다. 그 항목은 오류라고 가정해 바꾸지 않았다. App Store 설명에 명시된 아이폰 잠금화면 자막·이전/다음 대화 기능은 소개 원고에 추가했다. 후속 PR #21 반영 뒤 운영 본문을 확인했다. 공개 자체를 자연 발견 성과로 계산하지 않는다.
