# 05:30 KST · 공개 후 첫 고정 비브랜드 회차

두 API 모델 × 고정 질문 6개 = 정상 완료 12개. 들리 이름 후보·공식 웹 인용·노출된 자사 웹/스토어 검색 URL은 모두 0개였다. 새 가이드 공개 약 45분 뒤의 관측이며 색인 지연과 모델·검색 변동을 분리할 수 없다. 개선 효과의 부재나 향후 노출을 확정하지 않는다. 원자료는 `api-watch-2030-*.jsonl`, 누적 분류는 [검색·읽기·인용 구분](retrieval-observations.md)이다.

## 출처 확인

- Luna G01의 `cake.day`는 Google Play의 Cake 공식 웹사이트 링크 `mycake.me`를 따라갔을 때 도달한 주소다. 회사 사이트도 `mycake.me`로 연결한다. 익숙하지 않은 도메인이라는 이유로 비공식 출처로 분류하지 않았다. [Play 등록](https://play.google.com/store/apps/details?id=me.mycake&hl=en), [회사 사이트](https://cakecorp.com/ko/), [연결 대상](https://mycake.me/).
- Luna G03·G09의 `bbclearningenglish.org`는 이번 점검에서 BBC 소유 여부를 확인하지 못했다. 페이지 제목만으로 BBC 공식 출처라고 채택하지 않는다. 해당 답변이 인용한 URL이라는 사실과 출처의 소유권 검증은 구분한다. Sol G03에는 별도의 `downloads.bbc.co.uk` 원문 스크립트가 인용됐다.
- Sol G02의 British Council `/comment/206115`는 기존 검토에서 학습 계획 원문도 표시되는 페이지임을 확인했다. URL 경로에 comment가 있다는 이유만으로 사용자 댓글만 인용했다고 단정하지 않는다.

공개 가이드에 이번 답변의 미검증 수치나 효능 주장을 추가하지 않았다.
