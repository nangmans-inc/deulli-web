# 소비자 서비스 측정 범위

05:40 KST까지 실제 화면 관측은 기존 4개와 야간 7개, 총 11개다. API 183개와 합산하지 않는다. 이 중 브랜드를 먼저 알려준 ChatGPT 질문은 1개, 비브랜드 질문은 10개다. 정상 답변은 브랜드 1개·비브랜드 7개이며 나머지 비브랜드 3개는 Gemini의 거절 답변이다. 초기 헤드리스 드라이버 추출 실패 3개와 접근 실패는 이 11개에 포함하지 않는다.

| 서비스·조건 | 비브랜드 정상 | 거절 | 출처 검토 범위 |
| --- | ---: | ---: | --- |
| Gemini Flash, 로그인된 새 임시 대화, 초기 관측 | 2 | 1 | 표시 여부 관측, 전체 출처 URL 추출 아님 |
| ChatGPT, 임시 대화·개인화되지 않음 표시, 야간 | 1 | 0 | 실제 출처 링크 3개 확인 |
| Gemini Flash-Lite, 익명·헤드리스 | 1 | 2 | 인라인 출처 이름만 추출, URL 미추출 |
| Perplexity, 기본 모델 미표시·익명·헤드리스 | 3 | 0 | 앱 질문은 10개 출처 표시만, 공부법·팟캐스트 질문은 각각 10개 URL 추출 |

이 비브랜드 정상 답변 7개에는 들리 이름이 없었다. 방법을 묻는 답변과 앱을 추천하는 답변은 의도가 다르며 이를 서비스별 추천 점유율이나 전환율로 쓰지 않는다. 로그인 여부·모델·시점이 다르므로 서비스 간 우열도 비교하지 않는다.

사용자가 헤드리스 전용으로 지시하기 전의 네이티브 관측과 지시 이후의 헤드리스 관측을 기록에서 구분했다. 이후에는 사용자 창·커서·키보드·로그인 프로필을 사용하지 않는다. 접근 제한을 해결하기 위해 프로필이나 쿠키를 복사하지 않았다.

08:15·10:15 KST 후속 세 질문은 별도 계획이며 아직 완료 수에 포함하지 않는다. 실패하면 정상 답변 수를 늘리지 않고 관측 제약을 남긴다.
