# 넓은 질문 뒤의 실제 검색어

초기 G01–G09 및 야간 첫 두 회차의 공개된 검색 작업을 확인했다. 동반 JSON에 검색어와 원문 파일·질문·모델을 보존했다. 새 질문을 보내거나 후보 브랜드를 요청 문맥에 넣은 실험이 아니다.

- 공개된 검색어 133개 중 13개에는 한글이 있었고 120개에는 한글이 없었다. 문자 구성만 센 것이며 언어 판별이 아니다. 같은 답변의 여러 검색어는 서로 겹친다.
- 일반 영어공부 앱을 묻는 G01·G04의 8개 답변 모두 첫 검색 묶음의 각 검색어에 이미 특정 제품·제공자 이름 또는 해당 도메인 제한이 들어 있었다. Duolingo·Speak·ELSA·Cake·BBC 등의 공식 자료를 찾는 형태였다.
- 따라서 검색 도구 실행 여부와 열린 범주의 앱을 새로 발견하는 탐색은 같은 측정값이 아니다. 웹 출처가 붙었다는 사실만으로 폭넓은 시장 비교가 이뤄졌다고 해석하지 않는다.

## 해석의 한계

모델 내부에서 언제, 어떤 근거로 후보를 골랐는지는 관측하지 못한다. 첫 검색의 브랜드명을 근거로 학습 데이터·추천 가중치·광고·제휴 여부를 추정하지 않는다. 다른 질문이나 소비자용 서비스에서도 같은 패턴이라고 일반화하지 않는다. 들리의 페이지가 출처에 없었다는 결과를 오직 이 검색 방식 때문이라고 설명할 수도 없다.

이 기록은 검색어 선택 단계, 공개된 검색 URL, 최종 인용, 실제 추천을 구분하기 위한 것이다. 원래 사용자의 자연스러운 질문은 고정 관측에 그대로 유지한다. 이후 다른 검색 지시를 시험한다면 별도 진단으로 분리하며 원래 질문의 성과에 합치지 않는다.
