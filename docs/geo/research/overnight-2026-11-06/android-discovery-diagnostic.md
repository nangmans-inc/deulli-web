# Android 지원: 발견 실패와 직접 읽기를 구분

2026-11-06 KST. URL 지정 진단 D06, 두 모델 각 1회. 원문은 상위 연구 폴더의 `api-store-diagnostic-gpt-6-luna.jsonl`, `api-store-diagnostic-gpt-6-sol.jsonl`.

## 관측

이전 브랜드 질문 B02에서 Sol은 Android용 Google Play 앱을 확인하지 못했다고 답했다. 이후 [정확한 Google Play URL](https://play.google.com/store/apps/details?id=com.deulli.app&hl=ko&gl=KR)을 제공한 D06에서는 두 모델 모두 실제 `open_page` 작업을 기록했고, 들리의 이름·팟캐스트 영어 학습 설명·Android 앱 안내를 답변하며 해당 Play URL을 인용했다.

URL을 알고 나면 이 경로에서 읽을 수 있다는 결과다. 이전 검색 답변의 실패를 모든 크롤러의 접근 차단이나 Android 앱 부재로 설명할 수 없다. 검색 발견의 문제일 가능성은 남지만 색인·검색 순위·추천 정책 중 무엇이 원인인지는 이 진단으로 확정하지 못한다.

## 경계

- 주소를 프롬프트로 제공했으므로 자연 추천 성공에 포함하지 않는다.
- 모델의 영구 학습이나 이후 다른 사용자 답변의 변화가 검증된 것이 아니다.
- API 관측이다. 소비자용 ChatGPT·Gemini 화면을 측정한 결과로 쓰지 않는다.
- `open_page` 기록과 인용은 조회 근거이며, 기기 설치·실행 검증을 뜻하지 않는다.
- 같은 날 일반 웹 검색 도구에서는 해당 URL 열기에 실패했지만 직접 HTTP 조회와 두 API 모델의 URL 지정 열기는 성공했다. 접근 도구 간 결과가 다르므로 한 경로의 실패를 전면 차단으로 일반화하지 않는다.

## 반영

자체 소개의 iOS·Android 구분과 두 스토어 링크를 유지한다. 스토어와 지원 사이트에서 공식 홈페이지로 돌아오는 연결을 보강하는 변경을 준비했다. 새 가이드나 연결 작업이 실제 검색·추천을 개선했는지는 이후 독립 비브랜드 관측에서 확인한다.
