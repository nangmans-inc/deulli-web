# 들리 GEO 야간 작업 · 중간 결과

진행 중. 종료 기준은 2026년 11월 6일 오전 11시 KST다. 최신 자동 관측 수는 [누적 관측](overnight-results.md)에 표시한다. 이 문서의 아래 수치는 05:30 회차까지의 스냅샷이며 후속 회차로 바뀔 수 있다.

야간 두 회차는 PR #21의 새 콘텐츠가 공개되기 **전**이다. 해당 결과를 새 비교 가이드 공개 이후의 성과로 설명하지 않는다. 게시 이후 첫 정시 비브랜드 회차인 05:30 KST의 12개 답변에서도 들리 이름·공식 웹 인용은 없었다. 단기간의 이 결과로 이후 노출 여부를 예측하지 않는다.

원래 질문에는 브랜드명이나 제품 원고를 넣지 않았다. API 답변은 소비자용 ChatGPT·Gemini 화면 측정과 별개다. 반복 관측은 통계적으로 독립인 시장 표본이 아니며 전후 변화만으로 인과 효과를 확정하지 않는다.

새 비교 가이드의 D07 진단에서는 실제 `open_page`와 원문에 맞는 앱·자료 구분, 공식 페이지 인용을 확인했다. 이 진단을 더한 현재 API 기록은 183개다. 주소를 알려준 읽기 성공과 주소 없이 발견하는 추천은 별개다.

## 소비자 서비스 화면 관측

API와 별도로 익명 헤드리스 Perplexity에서 앱·공부법·팟캐스트 세 질문을 각각 새 컨텍스트로 측정했다. 세 답변 모두 들리 이름은 없었다. 공부법·팟캐스트는 출처 10개씩 링크를 추출했으며 앱 질문은 출처 수만 확인해 링크 검토가 불완전하다. Gemini 익명 Flash-Lite는 같은 세 질문 중 앱·공부법을 거절했고 팟캐스트만 정상 답변했다. 거절을 정상 추천 답변 분모에 넣지 않는다. 초기 Gemini 추출 실패 3건도 별도 보존하며 정상 답변에서 제외한다.

별도 Perplexity 브랜드 진단에서는 들리 이름만 제공하고 공식 홈페이지·App Store·Google Play 주소를 정확히 찾았다. 홈페이지와 공식 GitHub도 출처로 사용했다. 브랜드 식별 성공이며 일반 추천 성공이나 영구 학습의 증거가 아니다.

사용자의 입력 장치 보호 지시 뒤에는 네이티브 브라우저를 조작하지 않았다. 사용자 프로필·쿠키를 가져오지 않는 별도 헤드리스 환경을 사용했다. ChatGPT 익명 접근은 403, Google 검색은 사람 확인 화면이므로 새 답변·색인 측정에 포함하지 않았다.

## 실제 공개한 변경

검증한 [PR #21](https://github.com/nangmans-inc/deulli-web/pull/21)을 main에 반영했다. 운영의 네 페이지 모두 HTTP 200·새 본문을 확인했고, HTML SHA-256이 검증한 로컬 빌드와 일치했다.

- [영어공부 앱 선택 가이드](https://deulli.com/guides/english-study-apps/): 듣기·대화·어휘·학습 자료 선택을 나눠 공식 설명을 비교했다. 제작자 작성임을 밝혔다.
- [들리 소개](https://deulli.com/about/): iPhone 잠금화면 자막·대화 이동과 지원 범위를 명시했다.
- [팟캐스트 목록](https://deulli.com/podcasts/): 확인한 3개 에피소드의 앱 분류 난이도와 별도의 외부 학습 자료를 안내했다.
- [팟캐스트 학습 방법](https://deulli.com/guides/podcast-listening/): 따라 말하기의 과제와 스크립트 연구의 결과 범위를 구분했다.

기존 [영어공부 시작법](https://deulli.com/guides/starting-english-study/)도 운영 200을 확인했다. 사이트맵에는 10개 URL이 있다. 공개된 시작법 URL 및 후속 변경 네 페이지의 IndexNow 제출은 각각 HTTP 200으로 수락됐다. 제출 수락을 색인·추천 완료로 집계하지 않는다. 배포 서비스에 로그인하거나 직접 배포를 조작하지 않았다.

공개 GitHub의 홈페이지·소개·주제와 README 제품 설명도 현재 제품에 맞췄다. 이를 외부의 독립적인 추천이나 평가로 표현하지 않는다.

Google Search Console의 사이트맵 발견 수는 후속 화면에서 8로 표시됐다. 시작법·새 비교 가이드 모두 검사 당시 알려지지 않은 URL이었으며, 색인 요청 후 대기열 추가를 확인했다. 기존 5개와 합계 7개 요청 성공이고, 7개 색인 완료를 뜻하지 않는다. [실행 기록](../search-console-actions.md).

## 조사에서 확인한 문제

1. **페이지를 읽는 것과 검색에서 발견하는 것은 달랐다.** 정확한 공식 웹·Play URL을 제공하면 읽지만, 비브랜드 검색의 공개된 도구 기록에는 자사 웹·스토어가 없었다. [진단](android-discovery-diagnostic.md), [전체 구분](retrieval-observations.md).
2. **일부 첫 검색은 특정 브랜드를 포함했다.** G01·G04의 8개 답변 모두 첫 검색 묶음에서 이미 특정 제품·제공자를 찾았다. 내부 후보 선택 원인은 관측하지 못했다. [검색어 기록](search-query-observations.md).
3. **인용과 설명이 일치하지 않는 경우가 있었다.** BBC에 British Council 자료가 붙은 사례를 확인했다. 반대로 TED·British Council comment URL은 원문 확인 없이 잘못된 인용이라고 단정하지 않았다. [회차 검토](second-round-review.md).
4. **기능 이름의 범위가 달랐다.** 번역 자막·번역 음성·화자별 언어 선택, 잠금 화면 재생·자막·문장 이동을 나눠야 했다. [음성 언어](spoken-language-fit.md), [잠금 화면](lock-screen-fit.md).
5. **스토어 공개 정보와 검색 결과의 시점이 달랐다.** 최신 조회와 검색에 남은 과거 설명을 나눴다. 이메일 HTTPS 표기와 공식 홈페이지 연결 수정안을 준비했다. [스토어 원고](store-metadata-corrections.md).

## 공개하지 않은 작업

- 정책 사이트의 공식 홈페이지 연결은 [draft PR #5](https://github.com/nangmans-inc/deulli-policy/pull/5)다. 기존 사용자 수정·법률 본문을 보존했고 병합하지 않았다.
- 스토어 관리 화면에 수정안을 저장·제출하지 않았다.
- 외부 제품 소개 문안은 비공개 검토본으로 작성했다. 기존 Notion 초안을 수정하거나 커뮤니티에 게시·전송하지 않았다.
- Analytics 수치와 계정 정보는 비공개 로컬 기록에 두었다. 공개 연구 데이터에 포함하지 않는다.

## 검증

Astro·ESLint 오류·경고 0개, 빌드 성공. 7페이지 × 320/390/768/1440px에서 넘침·링크 이름·키보드 포커스 검사를 통과했다. 기존 브랜드 레이아웃을 사용했다. 연구 근거 ledger 검증은 오류·경고 0개였으며 상태는 `AI-audited; human verification pending`이다. 수치 검증과 연구 해석의 사람 검토는 같은 것이 아니다.

오전 11시까지 고정 비브랜드 관측과 누적 검토를 이어간다. 06:45·10:45 KST의 공식 홈페이지 찾기는 별도의 브랜드 진단이다. 노출 개선 여부는 실제 후속 답변·인용·색인 상태에서 확인하며, 문서·코드·게시물 수를 성과 지표로 대체하지 않는다.
