# 오전 11시까지 이어가는 GEO 작업

사용자 지시: 2026-11-06 오전 11시(한국 시간)까지 계속 작업. Vercel 로그인·배포는 제외한다. 기존 2시간 점검이 작업 종료 조건은 아니다.

추가 지시: 사용자 커서·키보드를 사용하는 네이티브 브라우저 조작을 중단한다. 이후 브라우저 작업은 분리된 headless 인스턴스에서 수행하며 기존 Chrome 창·입력·로그인 프로필은 조작하지 않는다. API 측정과 누적 검토는 계속 실행한다.

- 기간: 2026-11-05 18:30 UTC부터 2026-11-06 02:00 UTC까지.
- 독립 측정: 매시간 비브랜드 질문 6개 × 두 모델. 18:30~01:30 UTC의 8회, 총 96개 요청.
- 질문: 영어공부 어플 추천 / 영어공부하는 법 / 팟캐스트 영어공부 추천 / 영어 리스닝 앱 / 쉐도잉 공부 방법 / 출퇴근 영어공부 방법. 브랜드명과 제품 원고를 요청에 넣지 않는다.
- 각 시점 공개 페이지 HTTP 상태를 함께 저장한다. 새 가이드 404를 배포 완료로 취급하지 않는다.
- 30분마다 누적 응답·오류·브랜드 후보·공식 웹 인용·인용 도메인을 다시 집계한다.
- 오전 11시에 마지막 집계를 저장한다. 계획 96개보다 부족하면 누락을 명시한다.
- 실제 소비자 AI 화면과 API 결과, 브랜드 지정과 자연 발견, 언급 후보와 실제 추천을 구분한다.

현재 실행한 작업은 `geo-watch.py`(측정)와 `geo-overnight-review.py`(누적 검토·11시 최종 집계)다. 후자는 caffeinate와 함께 실행해 작업 중 유휴 수면으로 중단되지 않게 했다. 컴퓨터 종료·프로세스 강제 종료 시 지속을 보장할 수 없으므로 상태는 실행 핸들과 결과 파일로 확인한다.

결과: 같은 폴더의 `overnight-state.json`, `overnight-results.md`, `api-summary.md`, `api-watch-*.jsonl`, `http-watch-*.json`.

웹 변경 공개 확인 이후에는 06:45·10:45 KST에 D04 ‘공식 홈페이지 찾기’를 두 모델에서 한 번씩 추가 확인한다. 브랜드명은 주지만 URL은 제공하지 않는 진단이며, 비브랜드 고정 관측 96개와 분리한다. 4개 요청의 결과는 상위 연구 폴더 `api-site-check-*.jsonl`에 저장한다. Google Play URL 지정 진단 2개 역시 비브랜드 관측과 별개다. 계획 전체를 모두 정상 실행할 경우 기존 144개 + 야간 96개 + URL 진단 2개 + 홈페이지 진단 4개 = 246개 API 기록이 된다. 이는 계획 수이며 현재 완료 수를 뜻하지 않는다.

공개된 새 앱 비교 가이드가 검색 모델에서도 읽히는지 확인하는 D07 URL 지정 진단 1개를 추가한다. 이를 포함한 계획 API 기록은 247개이며, 비브랜드 질문 192개라는 계획 분모는 바뀌지 않는다. 소비자용 UI 표본·접근 실패·추출 실패는 이 API 수에 합치지 않는다.
