# 오전 11시까지 이어가는 GEO 작업

사용자 지시: 2026-11-06 오전 11시(한국 시간)까지 계속 작업. Vercel 로그인·배포는 제외한다. 기존 2시간 점검이 작업 종료 조건은 아니다.

- 기간: 2026-11-05 18:30 UTC부터 2026-11-06 02:00 UTC까지.
- 독립 측정: 매시간 비브랜드 질문 6개 × 두 모델. 18:30~01:30 UTC의 8회, 총 96개 요청.
- 질문: 영어공부 어플 추천 / 영어공부하는 법 / 팟캐스트 영어공부 추천 / 영어 리스닝 앱 / 쉐도잉 공부 방법 / 출퇴근 영어공부 방법. 브랜드명과 제품 원고를 요청에 넣지 않는다.
- 각 시점 공개 페이지 HTTP 상태를 함께 저장한다. 새 가이드 404를 배포 완료로 취급하지 않는다.
- 30분마다 누적 응답·오류·브랜드 후보·공식 웹 인용·인용 도메인을 다시 집계한다.
- 오전 11시에 마지막 집계를 저장한다. 계획 96개보다 부족하면 누락을 명시한다.
- 실제 소비자 AI 화면과 API 결과, 브랜드 지정과 자연 발견, 언급 후보와 실제 추천을 구분한다.

현재 실행한 작업은 `geo-watch.py`(측정)와 `geo-overnight-review.py`(누적 검토·11시 최종 집계)다. 후자는 caffeinate와 함께 실행해 작업 중 유휴 수면으로 중단되지 않게 했다. 컴퓨터 종료·프로세스 강제 종료 시 지속을 보장할 수 없으므로 상태는 실행 핸들과 결과 파일로 확인한다.
