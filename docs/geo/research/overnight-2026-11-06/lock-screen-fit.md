# 잠금 화면 질문의 기능 적합성

F06·F07의 두 모델 답변 4개를 원문으로 다시 확인했다. 들리를 발견하지 못했으나, 잠금 화면 오디오 재생과 자막 표시·문장 이동을 무조건 같다고 답한 것은 아니었다.

| 관측 | 답변의 구분 | 추가 확인 |
| --- | --- | --- |
| F06 Luna·Sol | 잠금 화면 자막을 확인하지 못했다고 명시하고 앱 안 대본·잠금 화면 오디오 재생을 구분 | 찾지 못했다는 결과를 기능을 제공하는 앱이 없다는 증거로 쓰지 않음 |
| F07 Luna | SpeakCove의 잠금 화면 문장 이동을 제시 | 공식 페이지는 책·문서·스캔을 읽는 TTS 앱을 설명한다. 해당 기능과 팟캐스트 카탈로그 지원은 별개 |
| F07 Sol | Phrabbit의 이어폰 문장 이동과 잠금 화면 저장 구간 이동이 같은지 불확실하다고 명시 | 기기 설치 검증을 하지 않았으므로 단서를 유지 |

[SpeakCove의 기능 페이지](https://speakcove.com/features/lock-screen)는 현재 읽는 단어와 이전·다음 문장 버튼을 잠금 화면에 표시한다고 안내한다. [공식 홈](https://speakcove.com/)의 중심 제품 설명은 PDF·책·문서의 음성 읽기다. 팟캐스트 학습 앱과 모든 조건이 일치한다거나 해당 앱에 팟캐스트가 없다고 단정하지 않는다.

들리의 최신 공식 App Store 설명으로 확인한 잠금 화면 자막·대화 이동은 `/about/`의 아이폰 질문으로 작업 브랜치에 명시했다. Android 잠금 화면에서도 동일하게 동작한다는 표현은 넣지 않았다. 최신 설명이 있다고 해서 모든 검색 결과에 즉시 갱신된다고 보지 않으며, 실제 자연 발견의 개선은 별도 관측 대상이다.

이 파일은 출처의 기능 범위를 대조한 기록이다. 여러 기기·OS·구독 조건에서 직접 앱을 설치하고 실행한 비교 결과가 아니다.
