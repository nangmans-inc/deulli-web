홈페이지는 검색 도구의 URL 열기에서 접근 오류가 났지만 별도 curl 요청은 HTTP 200이었다. 서버 장애와 검색 도구의 수집 실패를 구분해야 한다. Search Console URL 검사와 실제 크롤러 로그 없이는 원인을 확정할 수 없다.

## 가장 큰 실행 기회

추가로 여섯 질문을 각각 독립 검색하고 `query-1.txt`부터 `query-6.txt`에 출처와 응답 해시를 저장했다. `site:deulli.com`은 빈 결과였다. 브랜드와 범주를 길게 합친 쿼리에서도 무관한 결과가 반환됐다. 따라서 브랜드 검색으로 항상 공식 앱이 발견된다고 가정하지 않는다. 개별 결과는 검색 도구의 반환 표본이며 Google 순위가 아니다.

운영 홈페이지는 본문에 슬로건과 다운로드 링크 중심으로 노출된다. 제품 설명은 주로 메타데이터에 있다. 운영 HTML에는 여전히 가격 0의 Offer가 있고, 로컬 작업본의 About 설명과 앱 스토어를 연결한 JSON-LD는 아직 배포되지 않았다. 즉 추가 최적화 전에 기존 작업본의 배포가 우선이다.

검색에서 발견된 App Store 설명에는 학습 플레이어·단어장·쉐도잉·퀴즈가 명시돼 있다. 공식 사이트에서도 이 기능을 확인 가능한 설명으로 연결할 여지가 있다. 이번 원고는 변동 위험이 큰 가격·생성 분량·평점·효능 수치와 플랫폼별 세부 지원 주장을 피했다.

브랜드 단독 영문 검색에는 다른 국가의 동명 사이트·성씨도 등장했다. 제품 제목, 스토어, 공식 홈페이지에 '들리(deulli) + 영어 팟캐스트 학습 앱'을 일관되게 병기하는 것이 우선이다.

## 실행 우선순위

1. 기존 홈 작업본을 검증 후 배포하고 HTTP 감사 도구로 About 본문·가격 Offer 제거·스토어 연결 반영 확인.
2. 제품 소개 원고를 공개 페이지에 게시하고 홈에서 링크. 앱과 웹의 설명 불일치 정리.
3. 학습 가이드를 공개하고 실제 앱 이용 흐름을 보강. 존재가 확인된 콘텐츠만 예제로 링크.
4. Search Console에서 소유권·URL 검사·사이트맵 처리 상태 확인. 현재 계정 접근을 수행하지 않아 미확인.
5. 공개 페이지가 준비되면 외부 소개 원고 사용. 커뮤니티 규칙을 확인하고 운영자임을 명시. 무단 대량 게시나 가짜 이용 후기 금지.
6. API 또는 명시적으로 허용된 소비자 서비스 접근이 생기면 고정 질문 30개로 실제 AI 답변 측정. 게시 직후 반복 검사 대신 수집 시간을 둔 후 재측정.

## 측정 기준

브랜드 언급, 공식 도메인 인용, 사실 오류, 경쟁사 언급을 각각 기록한다. 인용은 답변의 실제 링크만 인정한다. 제품명 단어 출현은 추천과 다르므로 추천 여부는 사람 검토가 필요하다. 분모는 성공적으로 수집한 답변 수이며 오류·시간 초과·미측정은 제외하고 별도로 보고한다.

GA4에는 `chatgpt.com`, `perplexity.ai`, `gemini.google.com`, `copilot.microsoft.com` 등 실제 referrer/source 유입을 별도로 관찰한다. 직접 유입에 섞이거나 referrer가 유실될 수 있다. 스토어 클릭은 설치가 아니며 실제 가입·결제 귀속은 앱 측정 연결이 필요하다.
