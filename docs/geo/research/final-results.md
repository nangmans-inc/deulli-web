# 들리 GEO 작업 결과 · 2026-11-06

작업 시작: 한국 시간 01:04:25. 03:04:25까지 최소 2시간 동안 운영 반영과 고정 시점 측정을 수행했고, 이후 승인받은 Search Console 작업과 넓은 질문군 보강을 이어갔다.

## 확인한 결과

- **일반 질문에서 자연 추천되는 성과는 아직 없다.** 영어공부 앱 추천·공부 방법·팟캐스트 추천 등 브랜드명이 없는 API 관측 96개에서 들리 언급과 공식 홈페이지 인용이 0개였다. 이 중 사용자가 요청한 넓은 의도 9개×두 모델의 18개도 0개다.
- **브랜드를 알려주면 설명하는 답변은 얻었다.** 실제 ChatGPT의 개인화되지 않은 임시 대화에서 들리를 영어 팟캐스트 학습 앱으로 설명하고 App Store와 정책 사이트를 인용했다. 홈페이지는 인용하지 않았다.
- **공식 페이지를 직접 지정하면 읽고 인용했다.** 소개·학습 가이드·앱 선택 가이드·공식 팟캐스트 목록의 URL 지정 API 진단 4개 모두 실제 페이지 열기와 홈페이지 인용을 확인했다. 자연 발견과 구분한다.
- **실제 Gemini도 확인했다.** 독립 임시 대화의 앱 추천과 공부 방법 답변에 들리는 없었다. 팟캐스트 추천 질문은 거절 응답이라 추천 성과의 분모로 합치지 않았다.

전체 API 관측은 144개다. 고정된 30/60/90/120분 측정 48개, 브랜드·비브랜드 초기 표본, 기능 기반 질문, URL 지정 진단, 넓은 의도 표본이 포함된다. [집계](api-summary.md), [소비자용 화면 기록](consumer-browser-observations.md)을 구분해 보관했다. 반복 질문은 모델 학습이나 영구 노출 등록을 뜻하지 않는다.

## 실제 반영과 제출

- 홈페이지 FAQ·구조화 데이터·공식 제품 설명, 스토어 연결과 클릭 측정을 보강했다.
- 제품 소개, 팟캐스트 공부 방법, 학습 앱 선택 기준, 검증한 공식 에피소드 목록을 운영에 배포했다.
- 영어공부 시작법·목적별 앱 선택 가이드를 추가하고 홈·소개·기존 가이드에서 연결했다. PR #18 병합 완료. 운영 반영 상태는 실행 기록에 별도로 남긴다.
- 공개 저장소의 예전 사전신청 설명과 홈페이지 주소를 현재 서비스에 맞게 수정했다.
- IndexNow에 공개 URL을 제출하고 접수 HTTP 200/202를 확인했다. 이는 색인 완료가 아니다.
- Search Console 소유권 확인과 사이트맵 제출 완료. 사이트맵 상태 **성공** 확인. 홈페이지는 이미 Google 색인 상태였으며, 홈페이지·소개·학습 가이드·앱 선택 가이드·공식 팟캐스트 목록 5개 URL의 색인 요청 접수 완료.
- Google Analytics 유입과 스토어 클릭의 기준값을 확인했다. 운영 수치는 공개 저장소에 넣지 않고 로컬 비공개 기록으로 분리했다.

## 남은 노출 문제

브랜드 검색도 공식 홈페이지보다 App Store에 의존한다. API는 Android 지원·한국어 번역을 찾지 못하거나 비슷한 이름과 혼동하기도 했다. 스토어 연락처 표기와 홈페이지 연결을 개선할 수정안을 준비했지만 스토어 관리 화면에는 적용하지 않았다. [스토어 수정안](../content/store-metadata-patch.md).

Google의 새 페이지 색인과 AI의 자연 추천은 아직 확인되지 않았다. 다음 판단 기준은 같은 비브랜드 질문의 재측정에서 들리가 실제 추천 목록에 등장하는지, 어떤 URL이 근거로 인용되는지다. Search Console의 색인·검색 질의와 실제 유입도 함께 확인해야 한다. 이번 관측만으로 단기간의 노출 상승을 주장하지 않는다.
