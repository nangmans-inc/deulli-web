# AI 검색 노출 정비 · 2026-11-05

## 구현

- 홈에 서버 렌더링 제품 소개와 질문·답변을 추가했다. JavaScript 실행 없이도 읽힌다.
- 영문·한글 스크립트는 앱 README, 문장부터 다시 듣기는 기존 사이트 설명과 앱 재생 기능을 근거로 썼다.
- `MobileApplication`에 공식 스토어 주소와 핵심 기능을 연결하고, `Organization`과 안정적인 `@id`로 연결했다.
- 확인되지 않은 무료 가격 `Offer`를 제거했다. 가격은 앱 결제 안내와 스토어에서 확인하도록 설명한다.
- 기존 canonical, robots, sitemap은 유지한다. 운영 robots는 전체 크롤링 허용이며 홈과 사이트맵은 HTTP로 접근 가능했다.
- 본문과 다른 숨김 설명, 가짜 평점, 효능 수치, 경쟁사 비교는 추가하지 않았다.

## 배포 후 운영

이 변경은 로컬 구현이며 운영 배포와 검색 색인 등록은 별도다.

1. 배포 후 홈의 실제 HTML에 소개 문장과 최신 JSON-LD가 포함되는지 확인한다. CDN·WAF에서도 검색 크롤러가 차단되지 않아야 한다.
2. 소유자 권한으로 Google Search Console에 `https://deulli.com/sitemap-index.xml`을 제출하고 홈 URL 검사에서 색인 상태를 확인한다. 제출과 색인은 별개다.
3. 매달 같은 질문으로 검색 결과를 기록한다: “들리 앱은 무엇인가요?”, “한국어 번역을 보며 영어 팟캐스트를 듣는 앱”, “영어 팟캐스트 문장부터 다시 듣는 앱”. 날짜·검색 서비스·모델·질문·인용 URL·설명 오류를 함께 남긴다.
4. AI 서비스 유입, 스토어 이동, Search Console의 노출·클릭을 변경 전후로 비교한다. 질문 몇 회의 답변만으로 효과를 확정하지 않는다.
5. 기능·지원 기기·요금 정책 변경 시 본문과 구조화 데이터를 함께 갱신한다.

AI 답변의 인용과 순위는 보장할 수 없다. Google은 AI 검색에서도 기존 SEO, 접근 가능한 본문, 신뢰할 수 있는 사용자 중심 정보를 기본으로 안내한다. 이 작업도 그 기반을 보강한다.

근거: [Google Search Central의 AI 기능 안내](https://developers.google.com/search/docs/appearance/ai-features).

## antislop Delivery Gate

변경한 소개 영역 기준 ENERGY 1 / RHYTHM 1 / MOTION 1. 기존 들리의 Pretendard·네이비·블루를 재사용하며 질문과 답변을 스크립트처럼 이어 읽는 구성을 따른다.

- Hard Gate PASS: 확인 가능한 기능만 서술. 가짜 후기·수치·이미지 없음. 320/390/1440px에서 가로 넘침 없이 본문 노출. 실제 정책 URL과 기존 focus 스타일 사용. 정적 본문이므로 비동기 로딩·오류 상태는 해당 없음.
- Purpose Gate PASS: 새 장식·아이콘·그라데이션·애니메이션 없음. 제목 위계와 문단 간격으로 제품 설명을 읽게 한다. 기존 히어로 배경은 별도 영역으로 묶어 유지한다.
- Liveliness PASS: 소개 제목이 초점이며 블루는 링크, 여백은 소개·질문 구분에 사용. 기존 브랜드 서체와 문장 중심 구성이 제품 정체성을 유지한다.
- Craftsmanship PASS: Astro 검사·ESLint·프로덕션 빌드 통과. 기존 공유 테스트 53개 통과. 질문과 가격 안내는 들리의 실제 이용 판단에 필요한 내용으로 한정했다.
